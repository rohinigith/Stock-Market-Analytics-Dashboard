# Dashboard Overview

## Page 1 — Company & Market Overview

The first report page provides a company-level overview using a company slicer, company/sector/country cards, a country filled map, trading-volume gauge, turnover gauge, and report-date card.

## Page 2 — Company & Stock Details

The second report page provides a company distribution treemap, a detailed company/stock table, and a shares-traded gauge.

## Main Data Entities

| Entity | Example fields used in report |
|---|---|
| Companies | CompanyID, CompanyName, Sector, Country, today |
| StockPrices | Date, Volume, High |
| StockTransactions | Turnover, SharesTraded |

The PBIX file contains the complete report definition, visuals, data model, relationships and embedded report resources.
